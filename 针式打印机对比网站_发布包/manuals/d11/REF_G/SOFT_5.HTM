安装EPSON Status Monitor 3

EPSON Status Monitor 3可用于Windows Vista，XP，Me, 98, 2000和Windows NT 4.0。 使用它可让您监视打印机的状态，当打印机发生错误时可报警并提供排除故障的指导。

在下面情况时可使用EPSON Status Monitor 3:

  • 打印机通过并口[LPT1]或USB端口直接与主计算机连接。

  • 您的系统配置支持双向通信。

当直接连接打印机到计算机并按《首先阅读》中的描述安装打印机驱动程序时就自动安装了EPSON Status Monitor 3。要共享打印机，确保设置EPSON Status Monitor 3，以便在打印机服务器上能够监视共享打印机。 请参见设置EPSON Status Monitor 3和共享打印机。

注意:
  • 如果您使用“Point and Print”方法安装打印机驱动程序，EPSON Status Monitor 3将不能正常工作。 如果您想要应用EPSON
    Status Monitor 3，按照《首先阅读》描述重新安装驱动程序。
  • 当通过路由器连接远程的共享打印机时，由于路由器设置某些的原因，共享打印机不能使用错误和警告通知。

在使用EPSON Status Monitor 3之前，确认已经阅读了用户CD光盘中的README文件，此文件包含了关于此应用工具的最新信息。

设置EPSON Status Monitor3

按照下面步骤设置EPSON Status Monitor 3:

按在Windows Me 和98中使用打印机驱动程序或在Windows Vista,XP, 2000和Windows NT 4.0中使用打印机驱动程序中的描述打开应用工具菜单。

单击监视参数按钮，监视参数对话框出现。

下面为可用的设置。

选择通知

显示错误项复选框的开/关状态。

打开此复选框显示已选择的错误通知。

选择快捷图标

选择的图标显示在任务栏上。设置的样例显示在窗口的右边。单击快捷图标，您可容易地访问监视参数对话框。

接收共享打印机的错误通知

选中此复选框可以接收共享打印机的错误通知。

允许监视共享打印机

当选中此复选框时，共享打印机即可由其他计算机监视。

注意:
  如果服务器的操作系统是Windows Vista, 在检查前，当打开打印机属性窗口时，选择作为管理员用户运行。

注释：
单击缺省按钮可将全部的选项恢复为缺省设置。

访问 EPSON Status Monitor 3

进行下面之一可访问EPSON Status Monitor 3：

  • 请双击任务栏上打印机形状的快捷图标。要将快捷图标添加到任务栏，请转至应用工具菜单并遵循以下指导。

  • 打开应用工具菜单，然后单击EPSON Status Monitor 3图标。 要获得如何打开应用工具菜单，参见在Windows Me 和98中使用打印机驱动程序或在Windows Vista,XP, 2000和Windows NT 4.0中使用打印机驱动程序。

当您按上面描述访问EPSON Status Monitor 3 时,下面打印机状态窗口出现。

您可以在此窗口中查看有关打印机状态的信息。

注意:
在打印时想重新找回打印机状态是不可能的。
在此情况下，单击应用工具菜单中的EPSON Status Monitor3按钮，使用的打印机打开在左边的状态窗口。

安装EPSON Status Monitor 3

按照下面步骤设置EPSON Status Monitor 3:

确保打印机电源关闭，计算机在Windows下运行。

在计算机驱动器中插入打印机软件CD光盘。

注释：
  • 如果语言窗口出现，选择合适的语言。
  • 如果爱普生安装程序屏幕没有自动出现，双击我的电脑图标，右击CD光盘图标，在出现的菜单中单击打开，然后双击Epsetup.exe。

单击续继。 当软件许可协议屏幕出现时请阅读条款，然后单击同意。

单击自定义。

选择EPSON Status Monitor 3复选框，然后单击安装。

在出现的对话框中，确保选择您的打印机图标，并单击确定。按屏幕提示操作。

当安装完成时，单击确定。
