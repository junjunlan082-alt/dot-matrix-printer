故障查找

解决USB问题

如果您在通过USB连接使用打印机时有困难，请阅读本节中的信息。

确认计算机预安装有Windows Me, Windows 98或Windows 2000

您的计算机必须预安装有Windows Me, Windows 98或Windows 2000。您或许不能在没有配置USB端口的或从Windows 95升级到Windows Me, 98或2000的计算机上安装或运行USB打印机驱动程序。

有关您计算机的详细信息，请与经销商联系。

确认EPSON USB 打印机设备出现在设备管理器菜单上（仅对Windows Me和 Windows 98）。

如果在即插即用驱动程序安装过程完成之前将其取消，USB打印机设备驱动程序或打印机驱动程序将不能正确安装。

请按下述步骤检查安装结果，并重新安装驱动程序。

打开打印机，并将USB电缆插入打印机和计算机中。

右击桌面上的我的电脑图标，然后单击属性。

单击设备管理器标签。

如果驱动程序已正确安装，EPSON USB打印机设备应出现在设备管理器菜单中。

如果EPSON USB打印机设备未出现在设备管理器菜单中，请单击其他设备旁边的加号(+)查看已安装的设备。

如果USB打印机出现在其他设备下，则USB打印机设备驱动程序未正确安装。如果出现EPSON DLQ-3500K，则打印机驱动程序未正确安装。

如果USB打印机和 EPSON DLQ-3500K都没有出现在 其他设备下，单击 刷新或从打印机中拔下USB电缆，然后再将其插入打印机。

在其他设备下，选择USB打印机或EPSON DLQ-3500K并单击卸载。然后单击确定。

出现下面的对话框时，请单击确定。然后再单击确定，关闭系统属性对话框。

关闭打印机并重新启动计算机。然后按《首先阅读》中的说明重新安装驱动程序。

使用USB电缆时打印机运行不正确。

如果您的打印机无法正确使用USB电缆，请尝试以下解决方法之一或全部：

  • 确保您正在使用的是标准、屏蔽的USB电缆。

  • 如果您正在使用USB网络集线器（hub），请将打印机连接在网络集线器的第一层，或将打印机直接连接在计算机的USB端口。

  • 对于Windows 98，请尝试重新安装USB打印机设备和打印机软件。首先，使用控制面板中的添加/删除程序应用工具卸载EPSON打印机软件，然后卸载EPSON USB打印机设备。然后，按《首先阅读》中的说明重新安装软件。如果EPSON USB打印机设备未在添加/删除程序列表中注册，请访问光盘并双击Win 9x文件夹中的epusbun.exe。然后按屏幕提示操作。
