共享打印机

本节描述如何在标准的Windows网络中共享打印机。

网络上的计算机可以共享与其中一台计算机直接连接的打印机。直接连接打印机的计算机是打印机的服务器，其他计算机是客户机需要认证才能与打印机服务器共享打印机。客户机通过打印机服务器共享打印机。

根据Windows操作系统的版本和您在网络上的访问权，执行打印机服务器和客户机相应的设置。

设置打印机服务器

  • 对于Windows Me或98，参见对于Windows Me或98。

  • 对于Windows Vista,XP, 2000和Windows NT 4.0,参见对于Windows Vista,XP, 2000或Windows NT 4.0。

设置客户机

  • 对于Windows Me或98，参见对于Windows Me或98。

  • 对于Windows XP或2000，参见对于Windows XP或2000。

  • 对于Windows Vista, 参见对于Windows Vista

  • 对于Windows NT 4.0，参见对于Windows NT 4.0。

注释：
  • 当共享打印机时，确保设置EPSON Status Monitor 3以便打印机服务器可以监视共享的打印机。参见设置EPSON Status Monitor 3。
  • 当在Windows Me或98环境的服务器上时，您是Windows共享的打印机用户，在控制面板上双击网络图标并确保安装了“Microsoft网络文件和打印机共享”。 然后，在服务器和客户机上，确保安装了“IPX/SPX兼容协议”或“TCP/IP协议”。
  • 当连接到 Windows XP共享打印机上时，在打印期间，错误和警告通知不出现。
    安装 Windows XP Service Pack 1或更新可解决此问题。
  • 当通过路由器连接远程的共享打印机时，由于路由器设置某些的原因，共享打印机不能使用错误和警告通知。
  • 打印机服务器和客户机应该在相同网络系统上设置，并事先处于相同的网络管理下。
  • 由于Windows操作系统版本的不同，下列屏幕显示也不同。

将您的打印机设置为共享打印机

对于Windows Me或98

当打印机服务器的操作系统是Windows Me，98时，按照下列步骤设置打印机服务器。

单击开始，指向设置，然后单击控制面板。

双击网络图标。

单击配置菜单上的文件和打印共享。

选择允许其他计算机使用我的打印机复选框并单击确定。

单击确定，接受设置。

注释：
  • 当出现“插入磁盘”时，在计算机中插入Windows Me或98CD光盘。单击确定，并按屏幕上的提示进行操作。
  • 当提示重启计算机时，重启计算机，然后继续设置。

双击控制面板上的打印机图标。

右击打印机图标，并在出现的菜单中单击共享。

选择共享为，在共享名框中键入名称，并单击确定。如有需要键入注释和口令。

注释：
  • 在共享名中不要使用空格或连字符，否则会发生错误。
  • 当共享打印机时，确保设置EPSON Status Monitor 3以便打印机服务器可以监视共享的打印机。 参见设置EPSON Status Monitor 3。

您需要设置客户计算机以便可以在网络上使用打印机。详细信息请参见下面的链接部分。

  • 对于Windows Me或98

  • 对于Windows XP或2000

  • 对于Windows Vista

  • 对于Windows NT 4.0

对于Windows Vista, XP, 2000或Windows NT 4.0

当打印机服务器的操作系统是Windows Vista, XP，2000时，按照下列步骤设置打印机服务器。

注释：
必须具有本地计算机管理员身份的用户访问Windows Vista, XP，2000或Windows NT 4.0。

对于 Windows 2000或Windows NT 4.0打印服务器，单击开始，指向设置，然后单击打印机。
对于 Windows XP Professional打印机服务器单击开始，指向打印机和传真机。
对于Windows XP Home Edition打印机服务器,单击开始，再单击控制面板，然后单击打印机和传真机。
对于Windows Vista 打印服务器, 单击开始，控制面板，再单击硬件和声音，然后单击打印机。

右击打印机图标，并在出现的菜单中单击共享。

对于Windows XP，如果出现下列菜单，单击网络设置向导或如果您知道安全风险并想共享打印机而不运行该向导，单击这里。
在这种情况下，按照屏幕提示操作。

对于Windows 2000 或Windows NT 4.0打印机服务器，选择共享为（对于Windows 2000)或共享对于Windows NT 4.0)，然后在共享名称框中输入名称，然后单击确定。

对于Windows Vista,XP打印机服务器，选择共享此打印机，在共享名称框中键入名称。然后单击确定。

注释：
  • 对于共享名，不要使用空格或连字符，否则会出现错误。
  • 在Windows Vista中, 应在单击了更改共享选项 按钮后才可选择共享此打印机。

您必须设置客户计算机以便可以在网络上使用打印机。详细信息请参见下面的链接部分。

  • 对于Windows Me或98

  • 对于Windows XP或2000

  • 对于Windows Vista

  • 对于Windows NT 4.0

设置客户机

本节描述如何通过访问网络上的共享打印机来安装打印机驱动程序。

注释：
  • 要在Windows网络上共享打印机，需要设置打印机服务器。 有关详细信息，请参见将您的打印机设置为共享打印机(对于Windows Me或98)或对于Windows Vista,XP, 2000或Windows NT 4.0(对于Windows Vista,XP, 2000或Windows NT 4.0)。
  • 本节描述如何使用服务器（Microsoft工作组）访问标准网络系统上的共享打印机。如果因为网络系统而无法访问共享打印机，请询问网络管理员。
  • 本节描述如何通过访问打印机文件夹中的共享打印机来安装打印机驱动程序。也可以访问Windows桌面上的网上邻居或我的网络中的共享打印机。
  • 当您想在客户机上使用EPSON Status Monitor 3，每个客户必须从CD光盘中安装打印机的驱动程序和EPSON Status Monitor 3 。

对于Windows Me或98

按照下面步骤设置Windows Me或98客户机。

单击开始，指向设置，然后单击打印机。

双击添加打印机图标，然后单击下一步。

选择网络打印机，然后单击下一步。

单击浏览，然后出现浏览打印机对话框。

注释：
也可以在网络路径或队列名中键入“\\（与共享打印机相连的本地计算机的名称）\（共享打印机的名称）”。

单击与共享打印机相连的计算机或服务器以及共享打印机的名称。接着单击确定。

注释：
可以通过与共享打印机相连的计算机或服务器来更改共享打印机的名称。要确定共享打印机的名称，请询问网络管理员。

单击下一步。

注释：
  • 如果客户机中预先安装有打印机驱动程序，则需要选择是使用新的打印机驱动程序，还是使用当前的打印机驱动程序。当出现选择打印机驱动程序的提示时，根据信息选择打印机驱动程序。
  • 如果打印机服务器的操作系统是Windows Me或98，转至下一步。
  • 如果打印机的服务器操作系统不是Windows Me或98，转到从CD光盘安装打印机驱动程序。

确定共享打印机的名称，并选择是否使用此打印机作为缺省打印机。单击确定，并按屏幕上的提示进行操作。

注释：
可以更改共享打印机的名称，以便其仅出现在客户机上。

对于Windows XP或2000

按照下面步骤设置Windows XP或2000客户机。

如果具有高级用户身份或功能更强大的访问权限，即使不具备管理员身份也可以安装共享打印机的打印机驱动程序。

对于 Windows 2000客户机，单击开始，指向设置，然后单击打印机。
对于 Windows XP Professional客户机，单击开始，指向打印机和传真机。
对于Windows XP Home Edition客户机，单击开始，再单击控制面版，然后单击打印机和传真机。

对于Windows 2000，双击添加打印机图标，然后单击下一步。

对于Windows XP，在打印机任务菜单中单击添加打印机。

选择网络打印机（对于 Windows 2000）或网络打印机或与其它计算机连接的打印机（对于Windows XP），然后单击下一步。

对于Windows 2000，选择键入打印机名称，或单击下一步浏览打印机, 然后单击下一步。

注释：
在名称框中，您还可以键入共享打印机名或网络路径，如“\\(与共享打印机相连的本地计算机的名称)\(共享的打印机名称)。”

对于Windows XP，选择打印机浏览，然后单击下一步。

单击与共享打印机相连的计算机或服务器以及共享打印机的图标。然后单击下一步。

注释：
  • 可以通过与共享打印机相连的计算机或服务器来更改共享打印机的名称。要确定共享打印机的名称，请询问网络管理员。
  • 如果客户机中预先安装有打印机驱动程序，则既可以选择新的打印机驱动程序，也可以使用当前的打印机驱动程序。当出现选择打印机驱动程序的提示时，根据信息选择打印机驱动程序。
  • 如果打印机服务器和客户机具有相同的操作系统及相同的体系结构(x64/x86)，转至下一步。
  • 如果打印机的服务器操作系统不是Windows XP 或2000，转到从CD光盘安装打印机驱动程序。

对于Windows 2000，选择是否使用打印机作为缺省打印机，然后单击确定。

对于Windows Vista或XP，如果已安装其他驱动程序，选择是否将此打印机用作缺省打印机，然后单击确定。

确定打印机设置，然后单击完成。

对于Windows Vista

按下面步骤设置Windows Vista 客户机。

单击开始, 控制面板, 再单击硬件和声音, 然后单击打印机。

单击添加打印机图标。

单击添加网络，无线或Bluetooth打印机。

自动搜索共享打印机。

如果找到共享打印机，单击其图标，然后单击下一步。

如果没有找到共享打印机，单击我需要的打印机不在列表中图标。

选择浏览打印机并单击下一步。

在网络上出现一台计算机图标。

单击计算机图标。一台共享打印机图标出现。

单击安装驱动程序。

确保适合打印机的驱动程序名称显示如下，然后单击下一步。

如果任何打印机驱动程序已经安装，将出现设置为缺省打印机复选框。如果您想设置显示的打印机为缺省打印机，选择此复选框，然后单击下一步。

单击完成。

对于Windows NT 4.0

按照下面步骤设置Windows NT 4.0客户机。

如果具有高级用户身份或功能更强大的访问权限，即使不具备管理员身份也可以安装共享打印机的打印机驱动程序。

单击开始，指向设置，然后单击打印机。

双击添加打印机图标。

选择网络打印机服务器，然后单击下一步。

单击与共享打印机相连的计算机或服务器以及共享打印机的图标。然后单击确定。

注释：
  • 也可以在网络路径或队列名中键入“\\（与共享打印机相连的本地计算机的名称）\（共享打印机的名称）”。
  • 可以通过与共享打印机相连的计算机或服务器来更改共享打印机的名称。要确定共享打印机的名称，请询问网络管理员。
  • 如果客户机中预先安装有打印机驱动程序，则需要选择是使用新的打印机驱动程序，还是使用当前的打印机驱动程序。当出现选择打印机驱动程序的提示时，根据信息选择打印机驱动程序。
  • 如果打印机服务器的操作系统是Windows NT 4.0,转至下一步。
  • 如果打印机的服务器操作系统不是Windows NT 4.0，转到从CD光盘安装打印机驱动程序。

选择是否将此打印机用作缺省打印机，然后单击确定。

单击完成。

从CD光盘安装打印机驱动程序

本节描述当计算机服务器和客户机使用不同的操作系统时，如何在客户机上安装打印机驱动程序。

Windows XP的用户请安装系统自带的驱动程序，请参见《首先阅读》。

依据Windows操作系统版本的不同，下列屏幕显示也不同。

注释：
  • 在Windows Vista,XP,2000或Windows NT 4.0客户机中进行安装时，必须具有管理员身份的用户访问Windows Vista,XP,2000或Windows NT 4.0。
  • 如果计算机服务器和客户机使用相同的操作系统和体系结构，您不需要从CD光盘安装打印机驱动程序。

访问共享打印机，可能会出现提示。单击确定，然后按照屏幕提示从CD光盘安装打印机驱动程序。

在计算机CD驱动器中插入CD光盘，爱普生安装程序对话框出现。可单击取消可取消此对话框，然后键入客户机的打印机驱动程序所在的合适的驱动器和文件夹名称，然后单击确定。

当在Windows Vista,XP或2000中安装驱动程序时，出现“未找到数字签名”，单击是(对于Windows 2000), 仍然继续(对于Windows XP)或仍然继续安装此驱动程序软件(对于Windows Vista)，然后继续安装。

文件夹名称因正在使用的操作系统而异。

客户机操作系统

文件夹名称

Windows 98

\<Language>\WIN98

Windows Me

\<Language>\WINME

\<Language>\WIN2000

Windows Vista x86 Edition

\<Language>\WINVISTA

Windows XP Professional x64 Edition, Vista x64 Edition

\<Language>\WINVISTA_XP64

Windows NT 4.0

选择打印机名称，然后单击确定。按屏幕提示操作。

注释：
<
  • 如果您还想安装EPSON Status Monitor 3(仅对于Windows 98,Me,2000和NT4.0），有关指导请参见安装EPSON Status Monitor 3。
  • 如果您想在共享打印机上使用EPSON Status Monitor 3 ,在从CD光盘上安装了打印机驱动程序和EPSON Status Monitor 3 后，按“设置客户机”中的指导重新安装打印机驱动程序。
    在打印前，确保在“设置客户机”中选择了安装的打印机驱动程序。
  • 如果安装EPSON Status Monitor 3 时打开了Windows Firewall功能(推荐),可能不能监视共享打印机。
    如果此情况发生，按下面步骤启动监视功能。

添加EPSON Status Monitor 3 至Windows Firewall Exceptions 列表。

对于Windows XP:
单击开始, 控制面板, 再单击安全中心, 然后单击Windows Firewall。

对于Windows Vista:
单击开始, 控制面板, 然后单击安全下面的允许一个程序通过Windows Firewal。 如果用户帐号控制屏幕出现，单击继续按钮。

单击不阻挡标签，然后单击添加程序按钮。

单击浏览按钮, 选择eEBAgent.exe, 然后单击打开 按钮。

eEBAgent.exe位于下面位置:

Windows XP Professional x86 Edition 和Vista x86 Edition:
驱动器:\Program Files\Common Files\EPSON\ EBAPI\eEBAgent.exe

Windows XP Professional x64 Edition 和Vista x64 Edition:
驱动器:\Program Files(x86)\Common Files\EPSON\ EBAPI\eEBAgent.exe

在程序列表中检查eEBAgent.exe是否出现，然后单击确定按钮。

检查eEBAgent.exe是否添加到程序和维修列表（Windows XP）或程序或端口列表（Windows Vista）中且已选择了复选框（复选框带标记），然后单击确定按钮。

  • 如果客户机的操作系统是 Windows Vista, 在打印时可能不能弹出错误信息。

  • 如果服务器的操作系统是Windows Vista, 他可通过下面更改步骤进行修改。
    1. 在打印机属性窗口中打开共享标签。
    2. 单击更改共享选项按钮。
    3. 清除“客户机上等待的打印任务”复选框。

  • 在Windows Vista 和XP Professional x64 Edition中,如果打印机正在打印时，打印机电源关闭。通息错误可能不能弹出。
